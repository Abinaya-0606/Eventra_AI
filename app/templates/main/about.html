Eventra AI

Your Smart Event Companion

Eventra AI is an intelligent AI-powered event planning and management platform that helps users organize events efficiently with smart AI assistance.

It helps organizers plan, schedule and prepare college events with AI, while keeping rules and money calculations accurate.

Technology stack

PythonFlaskBlueprintsGroq APIRAGChromaDBHTML / CSS / JavaScript

Architecture

Policy questions (RAG)

  1. Question (English or Tamil)
  2. Tamil is translated for search
  3. Relevant chunks retrieved from ChromaDB
  4. If nothing relevant: "not enough information"
  5. Groq answers only from those chunks

AI Studio

  1. Form is validated by the backend
  2. Prompt sent to Groq (JSON output)
  3. Python checks the structure and does all math
  4. Result shown and editable

Budget calculation

  1. Event details entered
  2. Deterministic Python calculation
  3. Breakdown and approver shown

The application does not check live venue availability, book venues, or register participants.
